# The Partner Pact

A minimalist, multilingual website for **The Partner Pact** — a physical card deck designed to help couples approach everyday conflicts through clearer communication, shared missions, and a tactical mindset.

The website introduces the product, explains its concept, and invites preliminary email inquiries about printed editions. Digital editions are no longer available, and the website does not process orders or payments.

## Tech Stack

- **HTML5** (Semantic page structure)
- **Custom CSS** (Layout, responsive design, and visual identity)
- **GitHub Pages** (Static hosting and deployment)

## Key Features

- **Static & Lightweight:** No backend, database, user accounts, or JavaScript framework.
- **Multilingual:** Separate English, Spanish, and Czech pages.
- **Responsive:** Designed for desktop, tablet, and mobile screens.
- **Privacy-focused:** No unnecessary services or tracking infrastructure.
- **Direct Contact:** Preliminary inquiries about printed editions are handled by email.

## Architecture

A single repository contains the language versions and shared website assets.

```text
├── index.html        # English version
├── es/
│   └── index.html    # Spanish version
├── cz/
│   └── index.html    # Czech version
├── assets/           
│   └── img/          # Images and visuals
│   └── css/
│     └── style.css   # Shared visual styling
├── LICENSE.md
└── README.md
```

The site is intentionally simple: each language version is a static HTML page, with no checkout, payment processing, or automatic digital delivery.
